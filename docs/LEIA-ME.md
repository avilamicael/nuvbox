## 💡 Como Usar em Obsidian

### Abrir a Documentação
1. Abra Obsidian
2. Abra pasta: `docs/`
3. Comece em `INDEX.md`

### Navegar
- Clique em **links azuis** para ir para outro documento
- Use `Ctrl+O` (ou `Cmd+O` no Mac) para busca rápida
- Veja **backlinks** para contexto relacionado
- Use **graph view** para ver conexões

### Filtrar por Tag
- Todos os documentos têm tags (ex: #inicio, #producao, #troubleshooting)
- Use sidebar para filtrar por tag

## 📊 Formato Obsidian

Todos os documentos usam:
- **Frontmatter YAML** com metadados
- **Links internos** com `[[file]]`
- **Tags** com `#tag`
- **Aliases** para múltiplos nomes
- **Cross-references** entre documentos
